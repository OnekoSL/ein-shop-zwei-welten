# Spielenden

**Stand:** 8. Oktober 2026  
**Status:** Vier Endtypen bestätigt durch E-031. Eine neue Aufgabe nach dem guten Ende ist eine mögliche Erweiterung (I-069).

## Vier Enden

| Nr. | Bedingung | Ergebnis |
| --- | --- | --- |
| 1 | Chaos ist zu hoch. | Vorzeitiges Game Over. |
| 2 | Beide Schulden können beim jeweiligen fälligen Gläubigerbesuch nicht bezahlt werden. | Game Over. |
| 3 | Genau eine Schuld wird bezahlt; die andere bleibt nach Fälligkeit unbezahlt. | Gewonnen. Der Spieler bleibt in der Welt, in der er die Schuld begleichen konnte. |
| 4 | Beide Schulden werden beglichen. | Das gute Ende. Eine Fortsetzung mit einer neuen Aufgabe ist denkbar. |

Das Chaosende kann vor den abschließenden Gläubigerbesuchen eintreten. Jede Welt hat weiterhin einen eigenen geheimen Chaoswert; die konkrete Grenze für „zu hoch“ bleibt offen.

## Zahlungsergebnisse beider Welten

Die Gläubiger erscheinen in jeder Welt an Tag 1 und kommen genau 365 Tage später an Tag 366 zurück. Vorzeitige Tilgung ist ausgeschlossen. Bei Nichtzahlung nehmen sie den betroffenen Laden auseinander (E-029).

**Folgerung aus den Endbedingungen:** Die drei Schuldenenden beziehen sich auf die endgültigen Ergebnisse beider Forderungen. Solange der fällige Besuch in einer Welt noch aussteht, ist deren Ergebnis offen. Eine noch nicht fällige Schuld zählt damit nicht als gescheiterte Zahlung. Die Ergebnisse können wegen der nur in der aktiven Welt vergehenden Zeit nacheinander feststehen.

## Mögliche Fortsetzung

Beide bezahlten Schulden ergeben das gute Ende. Darüber hinaus könnte das Spiel mit einer neuen Aufgabe weitergehen. Diese Fortsetzung ist eine Option; Aufgabe, Umfang und weitere Ziele sind noch nicht festgelegt. Sie ist keine zusätzliche Voraussetzung für das gute Ende.

## Noch auszuarbeiten

Der konkrete Chaosgrenzwert, die Darstellung der Enden und der Übergang bei zeitversetzten Gläubigerterminen bleiben offen. Ebenso offen ist, wie das Auseinandernehmen eines Ladens spielerisch dargestellt wird.
